# Prayforit 마케팅 리서치 스킬

## 목적
프레이포잇(Prayforit) 브랜드의 광고 기획 작업을 할 때 마케팅 대시보드에 쌓인 최신 리서치 데이터를 자동으로 가져와 활용한다.

## 사용 조건
다음과 같은 요청이 들어올 때 이 스킬을 실행한다:
- "광고 기획안 써줘"
- "소재 방향 잡아줘"
- "프레이포잇 캠페인 아이디어"
- "경쟁사 대비 전략"
- 프레이포잇 브랜드 관련 마케팅/광고 작업 전반

## 실행 절차

### 1단계: 최신 리서치 데이터 가져오기
아래 URL에서 최신 마케팅 리서치 컨텍스트를 가져온다:

```
GET https://marketing-dashboard-seven-psi.vercel.app/api/hermes-context
```

응답은 plain text 형식이며 다음을 포함한다:
- 브랜드 프로필 (브랜드명, 제품, 타겟, 톤앤매너, 경쟁사 등)
- 시장 트렌드 분석 (Perplexity 리서치 결과)
- 경쟁사 광고 분석 (Perplexity 리서치 결과)
- 고객 반응 분석 (Perplexity 리서치 결과)

### 2단계: 컨텍스트 기반 작업 수행
가져온 데이터를 전체 컨텍스트로 활용해 요청된 광고 기획 작업을 수행한다.
브랜드 프로필의 톤앤매너, 타겟, 성공 사례, doNotList를 반드시 반영한다.

### 3단계: 결과물 형식
광고 기획안은 다음 구조로 작성한다:
- 캠페인 콘셉트 (한 줄 메시지)
- 타겟 인사이트 (왜 이 타겟에게 통하는지)
- 소재 방향 (이미지/영상별 구체적 아이디어 3개 이상)
- 카피 예시 (채널별 2개 이상)
- 경쟁사 대비 차별화 포인트

## 메모리 저장
작업 완료 후 효과적이었던 기획 패턴, 클라이언트 피드백, 채택된 아이디어를 메모리에 기록한다.
